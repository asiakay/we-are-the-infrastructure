# Methods

Methods translate the reasoning kernel into repeatable practices.

Initial method families:

1. Observe
2. Verify
3. Map
4. Diagnose
5. Locate Leverage
6. Sequence
7. Build Capability
8. Act
9. Reflect
10. Expand Possibility

A method should specify when to use it, required inputs, procedure, outputs, failure modes, and how competence can be demonstrated.
