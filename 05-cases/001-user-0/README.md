# Case 001 — User 0

## Purpose

This is the first real-world test of the WE ARE THE INFRASTRUCTURE reasoning kernel.

The case uses the framework's creator as **User 0** so that the method is tested against actual conditions before its practices are automated or generalized for other users.

## Case question

> How can existing knowledge, skills, relationships, projects, intellectual property, and other assets be converted more reliably into durable economic and institutional capability?

This question is provisional. It may be revised if observation shows that it embeds an unsupported diagnosis or defines the situation incorrectly.

## Working outcome

The case should determine whether WE ARE THE INFRASTRUCTURE can help a person move from a real situation to:

1. a more accurate understanding of the condition;
2. a defensible diagnosis;
3. a feasible intervention;
4. a capability that did not previously exist or was not previously reliable; and
5. new possibilities created by that capability.

## Method

The case will move through the reasoning kernel sequentially:

**Observe → Verify → Map → Diagnose → Leverage → Sequence → Build → Act → Reflect → Expand**

Stages should not be prematurely collapsed into one another. In particular, observation should not be rewritten to make a later diagnosis appear inevitable.

## User 0 rule

Friction is evidence.

If a question is difficult to interpret, a category does not fit the situation, an important relationship cannot be represented, or the method encourages unsupported assumptions, that problem should be captured as evidence about the framework itself.

The case is therefore doing two things simultaneously:

- using WATI to investigate a real condition; and
- using the real condition to investigate WATI.

This is the first resident-learner feedback loop of the operational framework.
