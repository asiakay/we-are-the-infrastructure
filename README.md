# WE ARE THE INFRASTRUCTURE

**WE ARE THE INFRASTRUCTURE** is a system for increasing people's capacity to understand their conditions, identify what can be changed, build the capabilities required to change it, act collectively, learn from the result, and expand what becomes possible next.

> **Success is measured by capability created—not content consumed.**

## What this repository is

This repository is the operational home for the WE ARE THE INFRASTRUCTURE framework. It connects research, reasoning, curriculum, methods, templates, casework, and software into one evolving system.

The core loop is:

**Observe → Verify → Map → Diagnose → Locate Leverage → Sequence → Build Capability → Act → Reflect → Expand Possibility**

The project has three primary expressions:

- **Book** — explains the ideas, history, and argument.
- **Curriculum** — teaches the method and develops human capability.
- **Software** — makes the method repeatable, navigable, and usable on real conditions.

All three share the same reasoning kernel.

## Design requirement

A capability should be able to persist beyond the individual who first develops or introduces it.

The aim is not simply to produce insight. The aim is to turn insight into durable individual, network, community, and institutional capability.

## Working hypothesis

> Can WE ARE THE INFRASTRUCTURE help a person move from a real situation they care about to a better diagnosis, a feasible intervention, and a new durable capability?

The software should emerge from proven practice rather than the other way around.
