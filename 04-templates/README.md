# Templates

Templates are **encoded practices**, not paperwork for its own sake.

Candidate templates include:

- Situation Brief
- Evidence / Verification Record
- System Map
- Power Map
- Asset Map
- Resource Flow Map
- Historical Timeline
- Capability Inventory
- Capability Gap Assessment
- Strategy Sequence
- Intervention Design
- After-Action Review
- Opportunity / Next-Possibility Map

Each template should correspond to a method and eventually be capable of becoming an interactive software workflow.
